
# Emotion Detector

## Project Description
An AI-powered web application that detects emotions in text using the Watson NLP Emotion Predict API and Flask.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Handles blank input and API errors.
- Provides a web interface using Flask.
- Includes automated unit tests and static code analysis.

## Technologies
- Python
- IBM Watson NLP Emotion Predict API
- Flask
- unittest
- Pylint

## Run the application
Install the dependencies and configure the Watson NLP service credentials, then run:

python server.py

Open http://127.0.0.1:5000 in your browser.
