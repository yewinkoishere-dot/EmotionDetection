# Emotion Detector

An AI-based web application that detects emotions in text using
the Watson NLP Emotion Predict API and Flask.

## Features

- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Handles blank input and API errors.
- Provides a Flask web interface.

## Technologies

- Python
- Watson NLP
- Flask
- unittest
- Pylint
